# Local development skills

Vendored from [obra/superpowers](https://github.com/obra/superpowers) at revision
`bb92a77741419a4ab5f06e711a283343f1ada0c3`.

- [Test-driven development](test-driven-development/SKILL.md): write a failing
  behavioral test before implementing a feature or fixing a bug. Includes the
  upstream supporting guide on writing good tests.
- [Verification before completion](verification-before-completion/SKILL.md):
  run verification commands and inspect their results before claiming success.

The upstream files are preserved unchanged. See [SUPERPOWERS-LICENSE](SUPERPOWERS-LICENSE)
for their MIT license.

Relative symlinks in `.agents/skills/` make these skills discoverable by Codex
while keeping their contents in this folder. They are repository-local; no
user-wide installation is required.
